# 提示词

提示词决定画面内容，CLI 参数决定模型、尺寸、质量和输出格式。先写清结果，再调参数。

## 生成

按以下顺序组织提示词：

1. 主体和用途：画面里有什么，用来做什么，例如产品图、广告、信息图、课堂讲义。
2. 构图：景别、视角、主体位置、留白和宽高比。
3. 可见细节：材质、颜色、光线、氛围和视觉媒介。需要照片感时直接写“photorealistic”或“真实照片”，相机型号和镜头参数只作为风格线索。
4. 限制：不要出现什么，必须保留什么。

复杂画面可以分段：

```text
Scene: ...
Subject: ...
Details: ...
Constraints: ...
```

人物和动作写清取景、比例、视线和与物体的交互，例如“全身可见，脚在画面内”“低头看打开的书”“双手握住车把”。

精确文字用引号写出原文，说明位置、字体和出现次数，并要求不要添加其他文字。生成后检查拼写和可读性。

需要透明背景时，在提示词中说明，并同时传 `--background transparent`，输出格式使用 png 或 webp。棋盘格图案不代表透明。

## 编辑

编辑提示词的核心结构：

```text
只修改 X。保留 Y 不变。不要添加 Z。
```

- X 写具体对象和变化，例如“把花瓶改成钴蓝色陶瓷”。
- Y 列出必须保留的细节：身份、脸、姿态、几何、布局、光线、色温、标签、背景和机位。
- Z 写排除项：额外文字、logo、水印、装饰和新元素。

局部编辑还要说明周边不变，例如饱和度、对比度、箭头、相机角度和相邻物体。需要像素级不变的区域，用图像合成，不要依赖反复提示。

一次只改一件事。把上一张输出作为下一次 `--image` 输入，重复关键约束，对比结果后再追加要求。

## 多图

按顺序给每张图分配角色，并说明如何组合：

```text
图 1 是室内场景，图 2 是人物，图 3 是服装。把图 2 的人物放进图 1，穿上图 3 的衣服，保留图 2 的脸和身份，匹配图 1 的光线。
```

第一张图只是 mask 和 markup 的作用对象，多图的角色由提示词决定。mask 和 markup 的输入准备与提示词示例见 `editing.md`。

## 参数

省略参数时，使用配置中的默认值；配置未设置时由 API 使用自身默认值，`quality` 默认为 `auto`。默认值通常更合适，没有明确理由不要调整。调低质量可能增加废片和重试，反而提高成本。

小字、密集标签、图表或幻灯片需要更清晰的文字时，可以先试 `--quality high`；仍不足再试 `xhigh` 或 `max`。`xhigh` 和 `max` 是默认效果不佳时的逃逸窗口，需要模型支持；OpenAI GPT Image 2.5/2.6 已支持。

`--complexity` 需要模型支持；OpenAI GPT Image 2.6 已支持。`low` 只在明确要减少模型发挥、保持局部改动时使用。

## 模型示例

OpenAI 当前的 GPT Image 2.5/2.6 提供 `flare` 和 `sunburst` 两种定位。以 2.6 为例：

- `gpt-image-2.6-flare`：速度优先。
- `gpt-image-2.6-sunburst`：细节、布局和编辑精度优先。

其他 provider 或后续模型按实际型号和定位选择。

比较模型或参数时，保持提示词、参考图、尺寸和输出格式一致，一次只改一个变量。

## 生成后检查

- 每个字都能读清，内容与要求一致；图表标签和关系正确。
- 人物身份、产品形状、标签和参考图细节保留。
- 编辑只改了要求的部分。
- 需要透明背景时，输出文件确实包含透明像素。
- 多张候选图按同一标准比较后再选。
